# The Rift Run · iPad-Installationshilfe

Diese Seite installiert das Lernspiel **The Rift Run** (Lesson Arcade) auf einem iPad, damit es offline läuft.

- Seite in Safari öffnen und zum Home-Bildschirm hinzufügen.
- Über das neue Icon die ZIP des Spiels aus der Dateien-App auswählen.
- Die ZIP wird nur lokal auf dem iPad verarbeitet und nicht hochgeladen.

Dieses Repository enthält ausschließlich die Installationshilfe, nicht das Spiel. ZIP-Bibliothek: fflate 0.8.2 (MIT, siehe `vendor/fflate-LICENSE.txt`).
